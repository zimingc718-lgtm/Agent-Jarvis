# 产品需求说明书

责任人：产品 owner

## 产品目标

交付 Agent-Jarvis 的第一个产品功能：一个本机运行的底部悬浮大模型对话 UI。用户登录 Agent-Jarvis 后，可以在底部悬浮输入条发起文本对话，选择 OpenAI、DeepSeek 或本地 OpenAI-compatible 模型，查看流式回复，停止生成，并保存最近会话。

## 用户范围

- 主要用户：本机使用 Agent-Jarvis 的个人用户。
- 管理用户：同一用户在模型设置页配置可用模型 Provider。

## 验收澄清（CR-20260908-floating-chat-functional-fixes，非新增需求）

- REQ-F-005：「不再追加输出」必须在服务端可观察——停止后服务端停止向模型请求，落库消息状态为 `stopped`。
- REQ-F-006：「切换」必须在浮窗 UI 上可观察——存在多个已启用 Provider 时渲染切换控件，且所选 Provider/模型随对话请求发送。
- REQ-F-007：「新增、编辑、启用、停用、测试」为五个独立可观察动作，各自需要独立验收证据；「编辑」不得产生重复配置。
- REQ-F-013：「恢复」必须在真实入口可观察——刷新后通过 `GET /api/conversations/[id]/messages` 取回消息并在浮窗重建。
- REQ-F-008：`oauth` 认证模式在本版本仅作展示，不可保存为可用 Provider。

### CR-20260908-ui-light-theme-minimal-home 澄清

- REQ-F-007「独立设置页」在本版本同时存在两个真实入口：首页「配置」弹窗与 `/settings/models` 深链页面，二者渲染同一 `ModelSettings` 组件。主题开关位于该弹窗的「外观」分区。
- REQ-F-002/003：展开后的对话面板高度上限为视口 65%，不得占满全屏（避免退化为通用聊天工具）。
- 首页「知识库概览」区域在当前版本不展示，属已批准的暂缓项，不构成需求删除。

## 非功能需求

| ID | 名称 | 优先级 | 描述 | 验收标准 | 状态 |
|---|---|---|---|---|---|
| REQ-NF-001 | 本机运行 | MUST | 第一版面向本机开发运行。 | 应用可通过本机命令启动，SQLite 数据保存于本地项目运行目录。 | APPROVED |
| REQ-NF-002 | 认证隔离 | MUST | 用户只能访问自己的 Provider 配置和会话。 | API 测试证明用户 A 不能读取或调用用户 B 的 Provider 与会话。 | APPROVED |
| REQ-NF-003 | 官方授权边界 | MUST | 第三方模型账号授权只使用官方支持方式。 | 系统不实现网页登录模拟、cookie 复用、抓包 token 或密码代登录。 | APPROVED |
| REQ-NF-004 | 真实入口验证 | MUST | 交付前必须通过真实 Next.js 应用入口验证主路径。 | 冒烟测试启动真实应用并走通登录后模型设置和底部浮窗对话主路径。 | APPROVED |

## 非目标

- 首版不实现图片、语音、多模态输入。
- 首版不实现工具调用和 Agent 编排。
- 首版不实现知识固化入口。
- 首版不实现公网生产部署。
- 首版不实现非官方第三方网页登录自动化。
