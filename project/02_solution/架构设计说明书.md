# 架构设计说明书

责任人：架构角色

## 设计目标

基于已批准产品需求，采用 Next.js 全栈架构实现本机运行的底部悬浮大模型对话功能。服务端负责登录态、Provider 配置、凭据加密、流式模型代理和会话持久化；前端负责 Google 登录入口、独立模型设置页、底部悬浮对话 UI 和流式展示。

## 总体架构

```text
Browser UI
  -> Next.js App Router pages
  -> Auth.js Google session
  -> API routes
  -> SQLite persistence
  -> Provider adapters
  -> OpenAI / DeepSeek / Local OpenAI-compatible endpoints
```

## 接口契约

### Provider

```ts
type ProviderAuthMode = "oauth" | "api_key" | "local" | "unsupported";
type ProviderKind = "openai" | "deepseek" | "local";

type ProviderSummary = {
  id: string;
  name: string;
  kind: ProviderKind;
  authMode: ProviderAuthMode;
  baseUrl: string | null;
  defaultModel: string;
  enabled: boolean;
  connected: boolean;
  secretPreview: string | null;
};
```

### ChatDelta

```ts
type ChatDelta =
  | { type: "start"; conversationId: string; messageId: string }
  | { type: "delta"; text: string }
  | { type: "stopped" }
  | { type: "error"; message: string }
  | { type: "done"; messageId: string };
```

## 外部 API 证据

| 来源 | 关键事实 | 影响 |
|---|---|---|
| OpenAI 官方 API 文档 | OpenAI API 使用 API key/Bearer 认证，Responses API 支持 `stream: true`。 | OpenAI 首版采用服务端 API key 托管和 Responses 流式。 |
| DeepSeek 官方 API 文档 | DeepSeek API 使用 Bearer Auth，提供 OpenAI 兼容 `base_url=https://api.deepseek.com`，可设置 `stream`。 | DeepSeek 首版采用 OpenAI-compatible adapter。 |
