## 关键接口

| 接口 | 所属模块 | 输入 | 输出 | 错误处理 |
|---|---|---|---|---|
| `getCurrentUser()` | MOD-AUTH | 请求上下文 | 当前用户或 null | 未登录返回 null，由页面/API 转换为重定向或 401 |
| `encryptSecret()` / `decryptSecret()` | MOD-DB | 明文凭据或密文字段 | 加密字段或明文 | 密钥缺失时返回配置错误 |
| `listProviders(userId)` | MOD-PROVIDER | 用户 ID | ProviderSummary[] | 只返回当前用户数据 |
| `testProviderConnection({baseUrl,secret})` | MOD-ADAPTER | base URL、可选 secret | `{ ok, message }` | 区分 401/403、404、超时（TimeoutError）、网络错误 |
| `saveProvider(userId, input)` | MOD-PROVIDER | 含可选 `id`、可选 `priority` | `{ id, created }` | 带 `id` 且属主则 UPDATE（空 secret 保留原密钥），否则 INSERT；未传 `priority` 且新启用时取「当前最大 + 1」 |
| `resolveActiveProvider(userId)` | MOD-PROVIDER | 身份 ID | `{ provider, model } \| null`（CR-20260909） | 在 `enabled && connected` 中按 `priority` 升序取首个；皆不满足返回 `null` |
| `reorderProvider(userId, id, direction)` | MOD-PROVIDER | 身份 ID、Provider ID、`"up" \| "down"` | boolean | 与相邻 Provider 交换 `priority`；仅属主生效；`PATCH /api/providers/[id]` 承载 |
| `setProviderEnabled / deleteProvider(userId, id)` | MOD-PROVIDER | 用户 ID、Provider ID | boolean | 仅属主生效，否则返回 false（路由转 404） |
| `PATCH / DELETE /api/providers/[id]` | MOD-PROVIDER | 属主 + id | `{ ok }` 或 404 | 未登录 401 |
| `sendProviderStream()` | MOD-ADAPTER | Provider、模型、消息、Abort signal、timeoutMs | AsyncIterable<ChatDelta> | 统一 `/chat/completions`；HTTP 错误体归一为 `error`；用户 abort→`stopped`；超时→`error` |
| `runChatTurn({conversationId?, systemPrompt?, ...})` | MOD-CHAT | 会话（可选）、Provider、模型、消息 | SSE（`start` 携带 conversationId） | 非属主会话 404；`ProviderSecretError`→400 可读；错误不写入 assistant 上下文 |
| `GET /api/conversations/[id]/messages` | MOD-CHAT | 属主 + id | `{ conversation, messages }` | 非属主 404，未登录 401 |
| `POST /api/chat/stream` | MOD-CHAT | 会话、消息（`providerId`/`model` 可选覆盖，CR-20260909） | SSE（`start` 携带 conversationId） | 缺 Provider 参数时走 `resolveActiveProvider`；无可用 Provider → 可读错误 + 不建会话（前端红字）；`停止` → `stopped` 且会话结束 |
