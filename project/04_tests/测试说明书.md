## 真实入口冒烟

真实入口冒烟必须启动实际 Next.js 应用，并使用浏览器或等效 HTTP/UI 驱动执行：

```text
打开首页（仅标题 + 配置/账号两个弹窗按钮，管理员身份免登录直接进入）
  -> 观察状态灯（无 Provider 时为「灭」）
  -> 打开「配置」弹窗（或深链 /settings/models）
  -> 配置两个 Provider（本地 OpenAI-compatible + 另一个），各自连接测试
  -> 调整优先级（上移/下移），关闭弹窗
  -> 刷新首页，观察加载探测后状态灯转「常亮」
  -> 使用底部悬浮输入条发送消息（不选择 Provider），验证用的是优先级最高者
  -> 观察流式输出与 Markdown 渲染
  -> 再发一轮，验证上下文回放
  -> 点击停止，验证服务端也停止、落库 stopped、会话结束
  -> 再发一条，验证是新会话（新 conversationId）
  -> 点击「新对话」，验证记录区清空
  -> 切换深色主题，刷新页面
  -> 验证呈现空会话（因上一步「新对话」）且主题保持
  -> 制造请求级错误（停掉本地模型服务后发送），验证输入框上方红字、不入上下文
```
