## 角色意见

标准档只取与本 CR 直接相关的角色意见。

| 角色 | 意见 | 处理 |
|---|---|---|
| 产品 owner | ①「默认关、要有开关」是用户原话，开关旁边必须看得见代价，否则「开了忘了」就是账单。②没事就什么都别出现——一条「暂无提醒」的系统消息本身就是打扰。③要能先试一次再决定开不开。 | CP-1 用量与开关同屏；CP-3 NOOP 静默；CP-7「现在唤醒」 |
| 架构角色 | ①不要复用 `runChatTurn`：它落用户消息、走工具循环、返回 SSE，每一项都是唤醒不该有的成本；一次 `makeCompleter` 调用即可。②授权必须在服务端，客户端定时器不能是花钱的权限来源。③产出不得回放，否则形成自激。 | CP-2 / CP-6 / CP-4 成文；立 DEC-040 |
| 测试角色 | ①调度器要用假时钟测「安静满一个间隔才触发」与「默认关不起定时器」，不能靠真等 60 秒。②「不回放」要用真实的下一轮发送内容断言，不能只断言状态值。③真实入口用「现在唤醒」走完整链路（一次非流式调用 → 转录区 → 刷新 → API 字段兼容 → 上限跳过），并断言模型只被调了一次。 | TEST-103 ④④′、TEST-101 ⑥、TEST-104 |
