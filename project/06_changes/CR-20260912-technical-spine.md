## 角色意见

标准档只取与本 CR 直接相关的角色意见。

| 角色 | 意见 |
|---|---|
| 产品 | 主轴换掉之后，卡片上最该先被看见的是「未对上」。这条数必须是数出来的，不能存——存下来的计数迟早和行对不上。 |
| 架构 | 不要为参数建表，也不要另立实体类型。`param:` 行与既有的 `source:` / `evidence:` 完全同形，解析器多一个分支即可，回滚后旧代码只是忽略它们。 |
| 模块开发 | 未知字段名从「拒绝」改成「按参数写入」是一次语义放宽，必须同时把结构字段名保留起来；否则一个瞄准 `title` 的写入会静默变成一条名叫 title 的参数，卡片上多一个假字段。 |
| 测试 | 「我方是否满足」没有任何来源可核对，因此它不是机器能守的东西——能守的是**工具写不到它**。这条要写成断言。 |
