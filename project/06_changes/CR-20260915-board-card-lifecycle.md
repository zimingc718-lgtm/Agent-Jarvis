回代码核对：`deleteEntity`（`src/lib/entities.ts:677`）已经存在且已经有真实可用的路由 `DELETE /api/entities/[name]`——缺的从来不是后端能力，是 UI 没有暴露入口，以及后端实现是不可逆的硬删（`rm`）。`KnowledgeDashboard.tsx` 的 `lane` 函数在列表下方常驻渲染一个 `<form>` 作为新增入口，三条泳道（友商/规则与准入方/客户）共享同一个 `lane`/`card` 实现。
