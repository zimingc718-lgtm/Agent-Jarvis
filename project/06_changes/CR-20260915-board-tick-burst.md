## 问题陈述

为验巡检的客户端 tick（`CR-20260911-scheduled-sweep` CP-4 的另一半），我用 Playwright 起了一个**真的、可见的**浏览器打开用户自己那台的看板。看板一挂载：

```
14:22:01.746Z  POST /api/entities/sweep → 本轮没有到期的采集源。
14:22:01.753Z  POST /api/entities/sweep → 本轮没有到期的采集源。
14:22:01.777Z  POST /api/entities/sweep → …
（150 毫秒内十余次）
```

原因：`KnowledgeDashboard` 的 `loadBoard` / `loadOverview` / `loadSweep` / `isVisible` 四个 prop 写成了**参数默认值** `loadBoard = () => …`。参数默认值在每次渲染都是一个新函数，而它们全在 effect 的依赖数组里——于是每次渲染都重跑三个 effect：看板与总览各重取一次、巡检 tick 立刻再发一次。

这正是那段注释里说「不该从隐藏标签页去打别人服务器」时想避免的形状，只是这次打的是自己的服务器，靠服务端「本轮没有到期的源」兜住了没真去抓别人。
