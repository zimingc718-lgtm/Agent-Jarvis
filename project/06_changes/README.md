- 级别：L1 / L2 / L3

- 影响需求：
- 影响模块：
- 影响任务：
- 影响测试：
- 当前证据：
- 方案选项：
- 选择理由：
- 回滚方式：
- 验收条件：
- 评审记录：

## 关闭条件

变更关闭必须满足：受影响文档已更新、受影响任务完成、必选验证通过、证据已保存、评审意见已关闭。
