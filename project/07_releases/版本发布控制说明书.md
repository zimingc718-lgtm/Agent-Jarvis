# 版本发布控制说明书

责任人：发布 owner

## 发布目标

首版发布目标为 `0.1.0`：交付本机运行的底部悬浮大模型对话 UI，支持 Google 登录、OpenAI/DeepSeek/本地 OpenAI-compatible Provider 配置、文本流式对话、停止生成和最近会话恢复。

## 发布门禁

发布前必须通过：

- G1：产品需求说明书 APPROVED。
- G2：架构、模块、测试说明书 APPROVED 且覆盖需求。
- G3：全部必选测试当前 PASS，含人工验证项已由真人执行并署名（当前 TEST-022 真实 Google 登录待验证）。
- G3.5：真实入口冒烟当前 PASS。
- G4：发布说明、发布清单和回滚方式有效。

## 回滚要求

发布必须保留：

- 上一版本发布清单。
- SQLite schema migration 回滚方式。
- 本地数据备份或可重建快照。
- Google OAuth、本地加密密钥、Provider 配置的恢复说明。
- 代码回退步骤。
