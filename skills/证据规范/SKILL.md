# 证据规范

用户定过一条规矩：**保持信息的准确性，没有就没有。**

这句话要能执行，必须落成判据，否则它只是一种态度。本文就是那套判据。看板上一个
错的容量数字，和一个对的容量数字，长得一模一样——**没有任何人能靠看屏幕发现它错了**。
证据链是唯一的兜底。

## 1. 什么算证据

一条证据 = **值 + 链接 + 原文定位**，三者缺一不成立。

- **值**：写到字段里的那个字符串，例如 `1200 MW`。
- **链接**：这个值出自哪个页面或文档的 URL。
- **原文定位**：该页面里**包含这个值的原话**，逐字照抄。

不算证据的东西：

- 「我记得他们官网写过」——记忆不是证据。
- 「行业内普遍是这个数」——常识不是证据。
- 「根据上下文推断应该是」——推断不是证据。
- 一个只有域名的链接，没有具体页面，也没有原话。

## 2. 写入前会被机器核对，先自己核对

`extract_fields` 会做三道检查，不通过就整条拒绝：

1. 条目必须已经在**本地知识库**里——值得出自我们确实存着的材料。
2. `quote` 必须在该条目正文中**逐字存在**（空白差异不算）。
3. `value` 必须出现在 `quote` **之内**。

第 2 条挡的是凭记忆编出来的引用。第 3 条挡的是更隐蔽的一种错：句子是真的，数字在
誊写途中飘了。**这两道检查都挡不住「读错了上下文」**——原文说的是「申请中」你写成
「已核准」，机器看不出来。那一层只能靠你自己老实。

所以：**先把原文读完整，再决定这个值说的是什么状态。**

## 3. 什么时候能直接生效，什么时候要等采纳

判据只有一条，而且不由你说了算：

> 来源域名是否在**该对象已登记的采集源**内。

- 同域 → 直接生效。
- 不同域 → 进待采纳区，用户点了才算。

**你不能声称「这是官网所以可信」。** 可信来源是用户在看板上登记的那几个，登记之外
一律走待采纳。被挡住时照实汇报：「已提议，来源 X 不在已登记源内，需要你采纳。」

想让某个来源以后能直写，正确做法是建议用户**把它登记为采集源**，而不是绕过闸门。

## 3b. 一条你永远不能填的东西：我方是否满足

技术参数写到对象上时带三样：名称、值、证据。**不带「我方满足 / 不满足」**——那是关于
我们自己产品的判断，任何来源页面里都没有，只有用户能填。

工具层面也是这么拦的：`extract_fields` 与 `propose_entity_update` 都写不了这个状态，
它只在看板上由人点。你能做的是把要求和数字准确地放上去，让那一次点击有依据。

## 4. 拿不准时怎么办

按这个顺序，**从上往下第一个能做到的就做它**：

1. **能找到原文** → 抓下来（`ingest_url`），再用 `extract_fields` 带引文写入。
2. **找得到但读不出确切值**（页面要脚本渲染、是 PDF 扫描件） → 照实说取不出正文，
   把链接给用户，让人来看。**不要用搜索摘要里的数字代替原文。**
3. **只有二手说法**（新闻转述、第三方数据库） → 可以入库当材料，但写字段时要说明
   这是转述，并且照样走待采纳区。
4. **什么都没有** → **就说没有。**空着的字段是诚实的空白，猜出来的字段是看板上的
   一个假事实，而且再也没人会去核。

## 5. 措辞：把不确定写在字面上

如果一个值本身带不确定性，让它在**值里**可见，不要藏在你的解释里：

- 好：`capacity = 约 1.2 GW（公告称"不少于 1.2 GW"）`
- 坏：`capacity = 1.2 GW`，然后在对话里补一句「大概是」。

原因很简单：对话会滚走，字段会留下。**只有写进字段的字会被将来的人读到。**

## 6. 采集状态不是内容变化

看板上「采集健康度」和「内容有没有变」是两件事，不要混着说：

- `未接入`——没配源。**没配源的安静，和对方真的没动静，看上去一模一样。**
- `陈旧`——配了源但太久没采到。
- `抓取失败` / `解析失败`——采到了但没拿到正文。**解析失败最危险**：页面可能正在变，
  而我们看不见。

汇报时要区分：「这个对象最近没有变化」和「这个对象我们根本没在看」是两句完全不同
的话。**后者说成前者，就是在编。**

## 7. 自检清单

写任何字段之前：

1. 我有链接吗？
2. 我能从**本地条目**里逐字抄出包含这个值的那句话吗？
3. 那句话真的是在说这个字段的意思吗？（状态、时间、口径有没有被我读串）
4. 来源在该对象已登记的采集源里吗？不在的话，我是不是老实说了「待采纳」？
5. 如果以上有一条做不到——我是不是选择了「就说没有」，而不是填一个差不多的值？
